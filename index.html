Fliqlo & Fliqo Run in Web – Flip Clock Screensaver with Full Custom Options

Fliqlo Web (commonly searched as Fliqo Web, Fliqo Run in Web, or Fliqlo Chromebook) is the definitive web-based recreation of the classic Solari split-flap clock. It brings the beloved minimalist screensaver aesthetic to any modern web browser without requiring Adobe Flash or desktop installer binaries.

How Fliqlo Web Solves the Chrome OS Screensaver Problem

Chromebook users face a persistent problem: Google Chrome OS does not support native .saver (macOS) or .scr (Windows) files provided by desktop flip clock developers. Consequently, Chromebook users have been unable to use the iconic Fliqlo screensaver. Fliqlo Web provides three comprehensive solutions:

  1. Browser Fullscreen Screensaver: Open the web app on any Chromebook and press F. The clock expands to native fullscreen with 60 FPS CSS 3D transforms. The cursor and bottom toolbar automatically fade away after 3 seconds of inactivity.
  2. Chrome Screensaver Extension: Download fliqlo-extension.zip directly from the bottom bar. Load it into chrome://extensions to gain automatic idle detection that launches the full-screen flip clock whenever your Chromebook is left untouched.
  3. Chromebook PWA / Kiosk Mode: Install the web app as a Progressive Web App onto your Chrome OS shelf, or deploy it in Chrome Kiosk mode for classrooms, reception desks, and smart home dashboards.

Full Web Version with Custom Options (Fliqo Run in Web)

Unlike desktop editions that have static styling, Fliqlo Web provides extensive customization options:

  • Time Display: Switch between 12-Hour format (with AM/PM split-flap badge) and 24-Hour format.
  • Flip Seconds: Real-time animated seconds card flipping downward with gravity drop shadows.
  • Mechanical Sound FX: Procedural plastic flap click audio synthesized via Web Audio API.
  • Themes: Classic Dark vignette, OLED Pure Black (#000000) for OLED battery preservation, Charcoal Slate, and Deep Midnight.
  • Digit Colors: Pure White, Vintage Cream (#f4ecd8), Retro Amber (#f59e0b), and Cyber Cyan (#06b6d4).
  • Font Families: Official Fliqlo Solari font, Barlow Condensed, Libre Baskerville serif, and Ubuntu humanist sans-serif.
  • Custom Sizing: Smooth scale from 60% to 140%, with independent horizontal and vertical sizing.
  • Curated Presets: Instant styles using ?preset=oled, ?preset=retro, ?preset=cyber, ?preset=neon, ?preset=minimal, or ?preset=solari.
  • URL Customization: Configure any option via URL search parameters (e.g. ?format=24h&theme=oled&color=amber&seconds=true).

Keyboard Shortcuts Reference

  • F: Toggle Fullscreen mode
  • S: Open Settings customization dialog
  • Space: Quick toggle between 12h and 24h format
  • I or ?: Open Fliqlo Web Guide and Chrome OS solutions modal
  • Esc: Exit fullscreen or close settings modal
